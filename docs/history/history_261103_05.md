## 발견 · 주의
- 이 PC 의 3000 포트는 다른 Node 프로그램이 쓰고 있다 → 확인은 3100 포트(게이트웨이 `GW_CORS_ORIGINS` 함께 지정)
- `_` 로 시작하는 Next.js 폴더는 라우트가 아니다 → 갤러리 경로 `/_design` → `/design`
- dev_server 가 가상환경을 잡고 있으면 `uv add` 가 설치를 못 한다 → 서버를 끄고 `uv sync`
- 세션 상태는 `useSyncExternalStore` 로(하이드레이션 안전) — 다른 전역 상태도 같은 방식으로
