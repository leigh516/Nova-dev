- 단계를 낮추면 높은 단계 답이 저장에서 빠졌다 → 원본 규칙대로 "답은 남긴다"(부모 보기를 풀었거나 섹션을 건너뛴 것만 빠짐)
- 한 개 고르는 질문에 목록 값이 들어오면 검사가 멈췄다 → 오류로 보고하게 고쳤다
- bash 헤어독 안의 `\\n` 이 실제 줄바꿈으로 바뀌어 파이썬 문법 오류가 두 번 났다 → `\n` 이 든 편집은 Edit 도구로 한다
- 진행 알림을 영어로 쓴 일이 반복돼 사용자가 여러 번 지적했다 → 규칙 · 훅 · 기억 파일 3중으로 막는다
