## 발견 · 주의
- 휴대폰 폭에서 가로 스크롤이 생겼다(격자 칸의 최소 너비) → `minmax(0, 1fr)` · `min-width: 0` 으로 고쳤다. 휴대폰에서는 머리 띠를 고정하지 않는다
- 자동 채움은 근거(E-*)가 있어야만 쓴다. 근거 없이 채우면 고객이 확인 없이 "맞아요"만 누르게 된다
- 진행 알림 일부를 영어로 써서 사용자가 지적했다(규칙 0 위반) → 기억 파일을 보강했다. 앞으로 짧은 알림도 한국어로만 쓴다
