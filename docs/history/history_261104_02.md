5. **README** — 새 프로젝트 시작 · 템플릿 저장소 안내 · 명령 표 · 화면 캡처, 마스터플랜 품질 게이트 체크

## 발견 · 주의
- 테스트 임시 폴더(`.pytest_tmp`)가 저장소 안이라 "저장소 밖" 검사에 걸림 → 복사에서 빠지는 폴더 안은 허용
- uv 가 Windows 에서 패키지 빌드 중 한 번 비정상 종료(0xC0000409) — 다시 실행하면 통과(일시적)
- `new_project.py` 는 서드파티 의존 없이 표준 라이브러리만 → 가상환경 없이도 실행 가능
