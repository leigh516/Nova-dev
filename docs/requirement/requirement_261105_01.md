## 의도 (INTENT — 해법을 적기 전에)
| 칸 | 내용 |
|---|---|
| 문제 | 사용자는 "모든 문장을 한국어로" 여러 번 지시했다. 그런데 긴 작업 중 도구 호출 직전에 쓰는 짧은 진행 알림이 영어로 미끄러진다(2026-11-04 하루에만 Stop 훅에 6회 잡힘). 지금 검사는 응답이 끝난 뒤(Stop)에만 돈다. 그래서 그 사이의 줄은 사용자 화면에 그대로 보인다. 교훈 원장에 기록한 뒤에도 같은 실수가 되풀이됐다. |
| 결과 | 영어 진행 알림이나 영어 도구 설명(description)을 쓰면 **바로 다음 도구 호출에서** 잡힌다. Claude 는 응답이 끝날 때까지 기다리지 않고 그 자리에서 한국어로 다시 쓴다. 기억에 기대지 않고 장치가 지킨다. |
| 영향 | `.claude/settings.json` 훅 배선 · `.claude/hooks/` · 복제본(new-project 로 물려받음) · 모든 세션의 도구 호출 지연(검사 비용) |
| 제약 | 검사기가 고장 나도 세션을 막지 않는다(조용히 통과). 같은 줄로 두 번 막지 않는다(끝없는 되풀이 금지). 판정 규칙은 Stop 훅과 **한 곳**(같은 함수)을 쓴다. 식별자 · 명령 · 경로 · 코드는 영어 그대로 허용한다. |
| 미해결 | 없음(T06-1.01 실측으로 답함) |

## 목적과 이유
같은 교정이 반복되면 방법의 결함을 의심한다(SOUL "구조를 본다"). 지금 결함은 이렇다. 검사 시점이 응답 끝이라서, 가장 자주 미끄러지는 자리인 도구 사이의 한 줄을 그 순간에 못 잡는다. 성공하면 사용자는 영어 진행 알림을 다시 지적하지 않아도 된다.
