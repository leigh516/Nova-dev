## 목적과 이유
체크리스트는 Nova 로 시작하는 모든 프로젝트의 첫 입구다. 여기서 빠진 질문은 PRD · SPEC 에서 다시 묻거나, 묻지 않고 가정으로 넘어가 화면 · 부품이 프로젝트마다 달라진다. 디자인 · 부품을 넉넉히 고르게 하면 공통 부품 재사용이 늘고, 없는 부품이 일찍 드러나 공통 영역(화면 공통 모듈)에 먼저 넣을 수 있다.
