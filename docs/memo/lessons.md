# 교훈 원장

> 교정 · 테스트 실패 · 검증 위반 · 사후기록에서 얻은 것을 **"트리거 → 규칙"** 한 줄로 남긴다. 같은 실수를 두 번 하지 않으려는 기록이다.
> 쓰는 법: `python nova.py learn add "<트리거>" "<규칙>" --ref <근거 ID>` · 찾기: `python nova.py learn find <낱말>` · 검사: `python nova.py learn check`(lint) — 명령 `/learn`(`.claude/commands/learn.md`)

## 규칙
- 한 줄 형식: `- [YYYY-MM-DD] <트리거> → **<규칙>.** (근거: <ID> · …)`
- **트리거**는 증상이 아니라 원인이 된 상황이다. **규칙**은 출력이 아니라 다음에 바꿀 행동이다
- **근거**에는 강한 식별자를 하나 이상 넣는다: `REQ-YYMMDD-NN` · `ISS-YYMMDD-NN` · `history_YYMMDD_NN` · `review_YYMMDD_NN` · `ADR-NNN`. 날짜 · 산문만으로는 나중에 어느 사건인지 찾을 수 없다
- 같은 트리거가 두 번 이상 나오면 마지막 줄 끝에 `(승급 후보)` 를 붙인다(`learn add` 가 자동으로 붙인다). 승급 — SOUL · STYLE · CLAUDE.md · 게이트로 옮기는 것 — 은 `/soul-review`(`.claude/commands/soul-review.md`) 가 제안하고 사람이 승인한다. 이 원장에서 바로 규칙 문서를 고치지 않는다
- 기계로 막을 수 있으면(검사 · 훅) 그쪽이 먼저다 — 교훈은 기계화가 안 될 때의 마지막 수단이다
- 쓰기는 본 작업 트리(main)만 한다(단일 기록자 — [ADR-008](../adr/ADR-008-parallel-bus-release.md)). worktree 의 교훈은 메시지 버스로 main 에 보낸다
