# 코어 용어집

Nova 코어(공통 화면 부품 · 공통 API · 공통 문서)가 쓰는 말을 한 번 정해 둔다. 화면 문구 · 도움말 · API 설명 · 문서가 같은 말을 쓴다([ui.md](ui.md) 8번 문구 통일 · [ux-heuristics.md](ux-heuristics.md) H2 현실 일치 · H4 일관성).

- **업종별 이름은 여기서 바꾸지 않는다.** 도메인 팩의 `packs/<팩>/glossary.md` 가 이 표의 **코어 용어 위에 덧씌운다**(오버레이 — 예: 코어 `항목` → 매장 팩 `예약`). 규칙: [STD-DOMAIN-PACK-001](../std/STD-DOMAIN-PACK-001.md) ① 용어
- 프로젝트 고유 용어(업무 용어)는 이 파일 아래 '프로젝트 용어' 절에 더한다. 코어 용어의 뜻을 바꾸려면 팩 오버레이를 쓴다
- 식별자(코드 이름)는 영어 그대로, 화면 · 문서에 보이는 말만 한국어로 정한다

## 코어 용어

| 용어 | 뜻 | 코드 · 식별자 | 쓰지 않는 말 |
|---|---|---|---|
| 항목 | 목록 화면에 한 줄로 보이는 업무 기록의 일반 이름 | `item` | 아이템, 레코드 |
| 보관 | 지우지 않고 목록에서 숨기기 — 되돌릴 수 있다 | `archive` | 아카이브 |
| 삭제 | 되돌릴 수 없게 지우기 — 확인 창을 거친다 | `delete` | 제거 |
| 실행 취소 | 방금 한 동작(보관 등)을 바로 되돌리기 — 토스트의 버튼 | `undo` | 언두, 되돌리기 |
| 저장 · 취소 · 다시 시도 | 버튼 기본 문구 — 컴포넌트 기본값을 쓴다 | — | 확인(저장 뜻으로), 재시도 |
| 조직(테넌트) | 데이터를 나눠 갖는 회사 · 매장 · 지점 단위 | `tenant_id` | 회사(모든 경우에), 사이트 |
| 역할 | 권한을 묶은 이름(관리자 · 직원 등) — `rbac.json` 에 먼저 정한다 | `role` | 롤, 등급 |
| 권한 | `<모듈>.<행위>` 꼴의 허용 — 예: `sample.create`(행위는 HTTP 메서드에서 — read · create · update · delete) | `permission` | 퍼미션 |
| 메뉴 | 화면 셸 왼쪽 · 위쪽의 이동 목록 — `menu.json` | `menu` | 네비 |
| 이벤트 | 서비스가 다른 서비스에 알리는 사실 — 토픽 `<도메인>.<개체>.<과거형 동사>` | `event` · `topic` | 메시지(사실 통지 뜻으로) |
