- 사람이 **무엇을 보라고** 지정해야 값어치가 있다 — 파일명이나 옆 `.md` 메모에 이 캡처가 무엇의 근거인지 적는다. 개인정보 · 비밀번호가 찍힌 캡처는 넣지 않는다
- 원본은 고치지 않는다. 분석 결과는 `docs/product/intake.json` 에 쌓이고, 이 분류의 분석 보고는 [outbound/screenshot](../../outbound/screenshot/README.md) 로 나간다
