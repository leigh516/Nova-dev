## 판독 규칙
- 화면보다 먼저 읽는다(기존 스키마는 설계 자유도를 좁힌다). 🔴 **참고 자료이지 적용 지시가 아니다** — 그대로 실행 · 채택하지 않고, 우리 모델과의 **차이표**(같음 · 다름 · 저쪽에만 · 우리에만)를 사람에게 보여 승인받는다
- 원본은 고치지 않는다. 분석 결과는 `docs/product/intake.json` 에 쌓이고, 이 분류의 분석 보고는 [outbound/db-sql](../../outbound/db-sql/README.md) 로 나간다
