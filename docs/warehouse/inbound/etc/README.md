# inbound/etc — 입고 · 읽는 순서 8

> 넣는 것: 위 어디에도 안 맞는 것 — 용어집 · 데이터 샘플 · 경쟁 제품 조사 · 참고 링크 모음

## 판독 규칙
- 가장 나중에 읽는다. **분류를 고민하다 입고를 미루지 않는다** — 애매하면 여기. 같은 성격이 3건 이상 쌓이면 전용 폴더를 만든다(입고 · 출고 양쪽 같은 이름으로 + `scripts/warehouse.py` `CATEGORIES` 에 추가)
- **대상 분석 결과(REA)** 는 `etc/rea/<대상>/` 에 — 허용 대상 · 비밀값 확인 · 실행 방법은 [대상 분석 규약](../../../conventions/reverse-engineering.md)
- 원본은 고치지 않는다. 분석 결과는 `docs/product/intake.json` 에 쌓이고, 이 분류의 분석 보고는 [outbound/etc](../../outbound/etc/README.md) 로 나간다
