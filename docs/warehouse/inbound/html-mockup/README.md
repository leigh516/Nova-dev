## 판독 규칙
- **실행 가능한 명세**로 본다 — 화면 · 상태 · 버튼 · 데이터 모양 · 역할을 *추출*한다(추측 금지). 목업의 색 · 글꼴은 옮기지 않는다(구현은 디자인 토큰만 — [design-system](../../../design-system/README.md))
- 원본은 고치지 않는다. 분석 결과는 `docs/product/intake.json` 에 쌓이고, 이 분류의 분석 보고는 [outbound/html-mockup](../../outbound/html-mockup/README.md) 로 나간다
