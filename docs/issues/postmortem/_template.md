| 시각 | 일 | 알았던 것 · 몰랐던 것 | 출처 |
|---|---|---|---|

## 측정
숫자 · 출력 원문만 적는다(해석은 다음 절).

## 근본 원인
"왜" 를 반복해 구조까지 내려간다. "실수했다" 에서 멈추지 않는다 — 실수를 가능하게 한 구조가 원인이다. 모르는 것은 모른다고 적는다.
1. 왜 —
2. 왜 —
3. 왜 —

## 재발방지
기계로 옮길 수 있는가를 먼저 묻는다. 위에서부터 고른다.

| 순서 | 처방 | 내용 | 상태 |
|---|---|---|---|
| 1 | 검사(lint · 테스트 · 게이트) 추가 | | |
| 2 | 훅 배선(`.claude/settings.json` — 승인 필요) | | |
| 3 | 교훈(`python nova.py learn add … --ref ISS-…`) | | |

근거 없이 차단을 걸지 않는다 — 기계화가 자명하지 않으면 재검토 조건을 건수로 적고(예: "같은 부류 2건이면") 교훈으로 둔다.

## 연결

- 요구 · 계획: REQ-… · plan_REQ_NN
- 이력: history_YYMMDD_NN
