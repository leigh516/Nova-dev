## 되돌리기
- 이전 태그가 없는 첫 판본이다. 이 판본을 쓰지 않으려면 태그 `v0.1.0` 이전 커밋으로 `git checkout <커밋>` 한다(이 판본은 저장소 파일만 바꾼다)
- 데이터 · DB: 운영 데이터가 없는 판본이다. 서비스 DB 는 `create_all` 로 만들어지며 마이그레이션 체계가 아직 없다(REQ-261104-11 R6) — 되돌릴 DB 변경이 없다
- 복제본 프로젝트: `nova.project.json` `upstream.base` 를 이 판본으로 받았으면, 다음 판본에서 `/sync-upstream` 이 스냅샷(`docs/releases/upstream/<시각>/`)으로 되돌릴 수 있다
- 확인 지점: 되돌린 뒤 `python nova.py check` 가 녹색인지
