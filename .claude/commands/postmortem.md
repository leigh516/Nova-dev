# /postmortem — 사후기록

인자: `$ARGUMENTS`
템플릿: [docs/issues/postmortem/_template.md](../../docs/issues/postmortem/_template.md)

"이거 왜 이렇게 됐지?" 는 사후기록이 있으면 3분, 없으면 3일 걸린다. 사람을 탓하지 않는다 — 같은 조건이면 누구라도 그랬을 **구조**를 찾는다.

## 절차
1. **템플릿 복사** → `docs/issues/postmortem/YYYY-MM-DD-<주제>.md`(한국어로 쓴다 — `docs_index --check` 가 한글 없는 문서를 잡는다)
1-1. 긴 본문은 `doc-writer` 에이전트에 1번 파일 경로와 기록 출력을 주고 맡겨도 된다(측정 값은 main 이 확인)
2. **타임라인 먼저** — 기억이 아니라 기록(로그 · 커밋 · 모니터링 · 대화 기록)에서. 시각마다 무엇을 알았고 무엇을 몰랐는지
3. **측정과 해석을 나눈다** — 측정은 숫자 · 출력 원문, 해석은 그로부터의 판단. 확인하지 않은 해석에는 **(검증 안 됨)** 을 붙인다
4. **근본 원인** — "왜" 를 반복해 구조까지. "실수했다" 에서 멈추지 않는다. 모르는 것은 모른다고 적는다(추정을 원인으로 올리지 않는다)
5. **재발방지 — 기계로 옮길 수 있는가를 먼저 묻는다**

   | 순서 | 처방 | 언제 |
   |---|---|---|
   | 1 | 검사(lint · 테스트 · 게이트) | 잡을 대상이 좁고 분명할 때 — 먼저 |
   | 2 | 훅(`.claude/settings.json`) | 도구 호출 시점에 잡을 수 있을 때 — 훅 순서 · 의미 변경은 사용자 승인(IDENTITY 경계) |
   | 3 | 교훈 | 위 둘이 안 될 때 — [/learn](learn.md) |

   근거 없이 차단을 걸지 않는다 — 기계화가 자명하지 않으면 재검토 조건을 건수로 적고(예: "같은 부류 2건이면") 교훈으로 둔다. 검사 · 훅을 새로 만드는 일은 이번 장애를 넓히지 말고 새 요구(`/req-new`)로 남긴다
6. **[/learn](learn.md)** — 재발방지를 한 줄로: `python nova.py learn add "<트리거>" "<규칙>" --ref <ISS-ID>`
7. **종결 연결** — `python nova.py issue set <ISS-ID> --status closed --repro-test "<파일>::<이름>" --postmortem "docs/issues/postmortem/<파일>.md"`

## 규칙
- 24시간 안에 — 늦으면 타임라인이 재구성으로 오염된다
- 사람 이름이 아니라 구조를 적는다
- P0 가 아니어도 배울 것이 크면 남긴다(선택)
