# 화면 확인의 함정 (Playwright · 헤드리스 브라우저)

psg05 의 헤드리스 드라이버가 실측으로 겪은 것 중 Nova(Playwright · Python)에도 해당하는 것만 옮겼다.

| 함정 | 증상 | 대처 |
|---|---|---|
| 뷰포트가 설정대로 안 됨 | 모바일 폭 캡처가 데스크톱 레이아웃 | 이동 뒤 `window.innerWidth` 를 되읽어 확인 |
| 빈 화면도 "성공" | 종료 코드 0 인데 PNG 가 하얗다 | 본문 노드 수 · 글자 수 하한으로 빈 화면 판정 |
| 외부 폰트 · favicon 404 | 콘솔 오류로 잡혀 늘 빨강 | 이 둘만 오류에서 제외(그 밖은 모두 오류) |
| 포트 충돌 | 지난 실행이 남아 엉뚱한 서버에 붙음 | 끝날 때 프로세스를 끄고, 시작 전 포트 비었는지 본다 |
| 겹친 요소 클릭 | 바깥 카드가 눌림 | 다른 후보를 품지 않는 가장 안쪽 요소를 고른다(role · 이름으로) |
| 다크 모드가 안 바뀜 | 토큰이 한 모드에만 정의 | 의미 토큰(`--color-bg-canvas` · `--color-bg-surface` 등)의 계산값을 두 모드에서 읽어 비교 |
| 애니메이션 중 캡처 | 토스트 · 창이 반쯤 | 상태 단언(`expect(...).to_be_visible()`) 뒤 캡처 |
